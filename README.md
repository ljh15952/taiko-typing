# donka-typing

태고의 달인 돈/카 패턴을 키보드로 연습하는 프로그램입니다.
패턴이 끝없이 이어지고, 양손을 번갈아 치도록 키가 정해집니다.

| 노트 | 왼손 | 오른손 |
|---|---|---|
| 돈 (빨강) | `F` | `J` |
| 카 (파랑) | `D` | `K` |

- 칠 음표는 항상 맨 왼쪽. 맞는 키를 누르면 그 음표가 사라지고 나머지가 왼쪽으로 당겨짐
- 표시된 손으로 정확히 쳐야 다음으로 진행 (틀린 키는 아무것도 바뀌지 않음)
- 묶음 사이를 넘어서도 손 순서가 이어짐
- 지금 칠 손은 아래 상태 표시줄의 `行 1, 列 3` 왼쪽 칸에 `L` / `R` 로 표시
- `Esc` 또는 `Q` 로 종료

## 모드

위 메뉴의 「モード(M)」에서 고릅니다. 바꾸면 처음부터 다시 시작합니다.

| 모드 | 내용 |
|---|---|
| ランダム(R) | 묶음 길이 1~8타, 돈/카 랜덤 (기존 동작) |
| 練習(P) | 태고의 달인 보면에 자주 나오는 배치를 난이도별로 출제 |

### 練習(P) 의 난이도

실제 보면의 난이도별 경향을 조사해서, 그 난이도에 자주 나오는 배치를 가중치를 두어 랜덤으로 냅니다.
화면의 간격은 태고 레인과 같은 비율입니다. 붙어 있으면 16분, 한 칸 띄면 8분, 묶음 사이는 4분 간격입니다.

| 난이도 | 실제 보면 경향 | 나오는 배치 (예) |
|---|---|---|
| かんたん(E) ★1~5 | 2분·4분 음표 중심, 가끔 단색 8분. 8분 복합도 거의 없음 | ドン, カッ, ドンドン(8분) |
| ふつう(N) ★1~7 | 8분 음표와 8분 복합이 중심. 16분은 가끔 단발로, 쉬운 배색만 | ドンドンカッ, ドンカッドン(8분), 가끔 ドコドン |
| むずかしい(H) ★1~8 | ★4부터 16분이 본격 등장, 8분 긴 복합. 복합보다 단색 16분·쉬운 복합을 물량으로 | ドコドン, ドコドコドン, ドドカッ, カカドン, ドカドカ(8분) |
| おに(O) ★1~10 | 16분 복합이 중심, ★7부터 24분, ★9부터 긴 복합 | 3연타 8종, 4·5연타 복합(24분에 많은 ドドドカ 포함), 단색 연타, 긴 복합(カカド 반복 등) |

- おに 의 2~4타 복합은 위키에 정리된 곡별 최다 출현 횟수를 참고해서 가중치를 정했습니다.
  나머지 가중치는 아래 자료의 설명을 바탕으로 정한 값입니다.
- 손 순서는 랜덤 모드와 같이 처음부터 끝까지 좌우 교대(交互)입니다.
  태고의 달인 오토 플레이도 첫 타를 왼손으로 시작하는 교대 방식입니다.

### 이동 모드 (音符を流す)

「モード(M)」→「音符を流す(S)」를 켜면 음표가 실제 게임처럼 왼쪽으로 흘러갑니다. 끄면 지금까지와 같은 정지 모드입니다.
ランダム 과 練習 의 모든 난이도와 함께 쓸 수 있습니다 (예: 이동 + かんたん, 이동 + ランダム, 정지 + ふつう).

- 속도는 「BPM(B)」에서 고릅니다 (60~240, 「その他(O)...」로 30~400 직접 입력).
  실제 게임처럼 흐르는 속도는 BPM 에 비례하고, 16분 한 칸의 간격은 BPM 과 상관없이 같습니다.
- 왼쪽의 판정 원(실제 게임의 판정 틀처럼 원 두 개) 한가운데에 음표가 들어왔을 때 칩니다.
  판정은 판정 원 바로 아래에 `良` / `可` / `不可` 로 나오고, 콤보는 10부터 함께 나옵니다.
- 손(L/R)은 판정과 상관없이 방금 누른 손의 반대로 바뀝니다 (L 을 누르면 다음은 무조건 R).
  누르지 않고 흘려보낸 음표로는 바뀌지 않아서, 아무것도 안 치면 L 로 고정됩니다.
- 반대 손으로 치면 `手順ミス` 입니다. 친 음표는 사라지고, 놓친 음표는 원래 색 그대로 흘러갑니다.
- 판정 폭은 실제 게임과 같습니다. 랜덤은 おに 기준입니다.

| 난이도 | 良 | 可 | 不可 |
|---|---|---|---|
| かんたん・ふつう | ±41.7ms | ±108.4ms | ±125.1ms |
| むずかしい・おに・ランダム | ±25.0ms | ±75.1ms | ±108.4ms |

## 확대 / 축소

메모장과 같은 방법으로 글자 크기를 바꿀 수 있습니다 (10% ~ 500%, 10% 단위).
현재 배율은 상태 표시줄에 표시됩니다.

- 「表示(V)」→「ズーム(Z)」→「拡大(I)」/「縮小(O)」/「既定の倍率に戻す(R)」
- `Ctrl` + `+` / `Ctrl` + `-` / `Ctrl` + `0`
- `Ctrl` + 마우스 휠

## 다운로드 (Python 없이 실행)

[Releases](../../releases) 에서 `memo.exe` 를 받아 실행하면 됩니다.
겉모양은 Windows 메모장과 같습니다.

처음 실행할 때 Windows SmartScreen 경고가 나오면
「詳細情報」→「実行」 을 누르세요. 서명되지 않은 exe 라서 나오는 경고입니다.

## Python 으로 직접 실행

```
pythonw donka_memo.py
```

표준 라이브러리만 사용하므로 추가 설치는 필요 없습니다.

`v` 로 시작하는 태그를 push 하면 GitHub Actions 가 `memo.exe` 를 만들어 Releases 에 올립니다.

```
git push origin v1.0.0
```
